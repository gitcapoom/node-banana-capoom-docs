# Node Banana Capoom

Welcome to the documentation for the **Capoom fork** of [Node Banana](https://github.com/shrimbly/node-banana).

This fork adds new nodes, features, and fixes for production use on a LAN-accessible workstation, while tracking the upstream project.

## What is Node Banana?

Node Banana is a visual workflow editor for AI image, video, audio, and 3D generation. You create, connect, and execute nodes on an infinite canvas to build media generation pipelines.

For the upstream documentation covering the base feature set, visit [node-banana-docs.vercel.app](https://node-banana-docs.vercel.app/).

## What Does This Fork Add?

This documentation covers everything that's **new or changed** compared to upstream:

### New Nodes
- [Video Compare](/docs/capoom/video-compare) — Side-by-side video comparison with Slide, Blend, and Difference modes
- [Video Input](/docs/capoom/video-input) — Load video files from disk
- [Image Compare Modes](/docs/capoom/image-compare-modes) — Added Blend and Difference modes to the existing slider

### Enhanced Nodes
- [Output Node](/docs/capoom/output-node) — Universal input handle, Output Now export, performance fixes
- [3D Viewer](/docs/capoom/glb-viewer) — Three.js viewer with file persistence and background pin toggle
- [Gaussian Splat Viewer](/docs/capoom/gaussian-splat-viewer) — Camera animation, video export, depth capture, COLMAP export
- [Generate 3D](/docs/capoom/generate-3d) — Carousel history with settings snapshots

### New Features
- [Output Now](/docs/capoom/output-now) — One-click export with sidecar JSON
- [LAN Access](/docs/capoom/lan-access) — Network path support and web-based directory browser
- [Cost Tracking](/docs/capoom/cost-tracking) — Per-generation and session cost display
- [Media Handling](/docs/capoom/media-handling) — Video/audio externalization, blob URL conversion
- [WorldLabs Enhancements](/docs/capoom/worldlabs) — Panorama preview, multi-image upload, auto-save
