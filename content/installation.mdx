# Installation

## Prerequisites

- Node.js 18+
- npm
- At least one AI provider API key

## Clone the Fork

```bash
git clone https://github.com/gitcapoom/node-banana-capoom.git
cd node-banana-capoom
npm install
```

## Environment Variables

Create a `.env.local` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key
OPENAI_API_KEY=your_openai_api_key          # Optional
KIE_API_KEY=your_kie_api_key                # Optional, for Kie.ai (Sora, Veo, Kling)
WORLDLABS_API_KEY=your_worldlabs_api_key    # Optional, for WorldLabs Marble
REPLICATE_API_KEY=your_replicate_api_key    # Optional
FAL_API_KEY=your_fal_api_key                # Optional
```

## Start the Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in Chrome.

### LAN Access

This fork binds to `0.0.0.0` by default, so the server is accessible from other machines on your local network. See [LAN & Network Access](/docs/capoom/lan-access) for details.

## Production Build

```bash
npm run build
npm run start
```

## Keeping Up with Upstream

This fork tracks `shrimbly/node-banana` as the `upstream` remote:

```bash
git remote add upstream https://github.com/shrimbly/node-banana.git
git fetch upstream
git merge upstream/develop
```

## Verify Installation

1. Open the app in Chrome
2. Add a Prompt node (Shift+P) and a Generate Image node (Shift+G)
3. Connect them and click Run
4. If an image generates, your API keys are working

For additional installation help, see the [upstream installation guide](https://node-banana-docs.vercel.app/installation).
