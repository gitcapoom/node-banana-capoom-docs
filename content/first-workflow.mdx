# Your First Workflow

For a step-by-step tutorial on building your first image generation workflow, see the [upstream guide](https://node-banana-docs.vercel.app/first-workflow).

The basic flow is:

1. **Add a Prompt node** — Shift+P or from the floating action bar
2. **Add a Generate Image node** — Shift+G
3. **Connect them** — Drag from the Prompt's text output to the Generate node's text input
4. **Configure** — Write a prompt, select a model
5. **Run** — Ctrl+Enter or click the Run button
6. **View results** — Generated images appear in the node with carousel navigation

## What's Different in This Fork

After you're comfortable with the basics, explore these additions:

- **[Output Now](/docs/capoom/output-now)** — Connect an Output node to export results with a single click
- **[Video Compare](/docs/capoom/video-compare)** — Compare two video generations side by side
- **[Cost Tracking](/docs/capoom/cost-tracking)** — Watch your API spend in real-time in the header
